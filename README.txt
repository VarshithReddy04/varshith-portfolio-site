VARSHITH REDDY PORTFOLIO
========================

This portfolio uses plain HTML, CSS, and JavaScript. No Node.js or npm is required.
No profile photo is used.

FILES
-----
index.html  - Portfolio content and sections
style.css   - Visual design, responsive layout, and animations
script.js   - Mobile navigation and automatic copyright year

RUN LOCALLY
-----------
1. Extract this ZIP folder.
2. Open the extracted folder in VS Code.
3. Open index.html in a browser, or use the Live Server VS Code extension.

BEFORE PUBLISHING
-----------------
1. In index.html, replace https://github.com/ with your actual GitHub profile URL.
2. Replace https://www.linkedin.com/ with your actual LinkedIn profile URL.
3. Replace the placeholder GitHub project link with the real Metadata Extractor repository.
4. Check all resume details and contact emails.

GITHUB PAGES
------------
1. Create a GitHub repository named varshith-portfolio.
2. Upload index.html, style.css, script.js, and this README.txt to the repository root.
3. Open repository Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select main and / (root), then Save.
6. Wait for deployment. GitHub will show the public website URL in Settings > Pages.

PRIVACY
-------
The public portfolio intentionally excludes home address, date of birth, and parents' names.
